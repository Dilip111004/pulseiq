# PulseIQ – Phase 2

## Workforce Analytics & Intelligence Platform

PulseIQ is a workforce analytics platform developed for the fictional organization Zenith Nova Technologies.

Phase 2 introduces interactive dashboards, cross-department analysis, AI signals, executive reporting and automated monthly reporting.

- AI Signals

## Technology Stack

Python, Streamlit, Pandas, DuckDB, Plotly, SQL, OpenPyXL and FastAPI.

## Monthly Reporting

Automated monthly Excel reporting packs with PowerShell execution and Windows Task Scheduler integration.
